# IDN-08 Leaving and removing members

features.md: "The owner can remove people. Anyone can leave, and then starts again with their own empty fridge."
The shared fridge, list, plans and profiles stay with the household; the person who goes gets a new personal
household. Ownership can be handed over, which is also how an owner leaves.
