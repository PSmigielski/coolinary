# GW-12 Savings routes

Releases R2 (counters and monthly report) and R3 (shareable savings card).

## Goal

Show the household what Coolinary saved them — euros and kilograms, from food used before expiry and items bought
on offer (features.md §2 "Savings and household") — and in R3 let them share a card. Kitchen keeps the ledger (D8).
