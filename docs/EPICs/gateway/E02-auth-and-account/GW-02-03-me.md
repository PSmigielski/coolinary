## Goal

The app learns who is signed in, whether the account is anonymous, and which household and member it belongs to,
without a call to identity.

## Business rules

1. Built only from the verified JWT (exists; fields extended). No gRPC call.
2. `email` is `null` for anonymous accounts.
3. `tokenExpiresAt` lets the app refresh the JWT early (MOB-01 refreshes when < 2 minutes remain).

## Contract

`GET /v1/me` — `auth: true`, tag `account`.

```json
200 {
  "id": "usr_...", "email": "ewa@example.com", "isAnonymous": false,
  "householdId": "0192...", "memberId": "0192...", "plan": "free",
  "tokenExpiresAt": "2026-11-01T10:15:00Z"
}
```

401 `unauthorized`.

## Data

No storage.

## Errors

| Case | HTTP | `code` |
|---|---|---|
| No or invalid token | 401 | `unauthorized` |

## Acceptance criteria

- [ ] Anonymous token → `isAnonymous: true`, `email: null`.
- [ ] `tokenExpiresAt` equals the JWT `exp`.
- [ ] No gRPC call is made (fake services count zero calls).
